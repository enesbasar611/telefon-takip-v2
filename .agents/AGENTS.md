# Project Rules

- **Do NOT run `npm run build` while the development server (`npm run dev` / dev server) is running.** Doing so causes database connection conflicts and builds to fail. Always ensure the development server is stopped before compiling a production build.
- **Her yapılan değişiklik, eklenen özellik veya hata düzeltmesi istisnasız olarak `JOURNAL.md` dosyasına kaydedilmelidir.**
